Hi, my name is Shahar Glazner! I'm a software engineer based in Tel Aviv who
loves building products, teams and open source software.

I'm one of the people behind [Keep](https://github.com/keephq/keep), the
open-source AIOps and alert management platform. Most of my days are spent
somewhere between backend systems, observability and developer tooling.

This blog is where I write about engineering, open source and whatever else
I happen to be thinking about.

If you want to contact me, you can reach me via one of the following
communication channels:

* find me on [GitHub](https://github.com/shahargl)
* reach out to me on [X](https://x.com/shaharglazner)

## About this Website

The website is written in Markdown and built with a small Python script. It
is hosted on GitHub Pages and the source code can be found on
[GitHub](https://github.com/shahargl/blog).

Every page is also available as plain Markdown. Look for the "view markdown"
link at the bottom of a page.
